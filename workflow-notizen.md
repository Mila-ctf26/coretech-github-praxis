# Workflow-Notizen

## Remote-Verbindung

Mit `git remote -v` kann ich prüfen, ob mein lokales Repository mit einem Remote-Repository verbunden ist.

## Push

Mit `git push` sende ich lokale Commits an GitHub.

## Pull

Mit `git pull` hole ich Änderungen von GitHub in mein lokales Repository.

## Merge-Konflikt

Ein Merge-Konflikt kann entstehen, wenn dieselbe Zeile in zwei Branches unterschiedlich geändert wurde.

## Commit und Push

1. Änderungen mit `git status` prüfen.
2. Dateien mit `git add` zur Stage hinzufügen.
3. Mit `git commit -m "Nachricht"` einen Commit erstellen.
4. Den aktuellen Branch prüfen.
5. Mit `git push` den Commit an GitHub senden.
