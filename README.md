# CoreTech GitHub Praxis

## Kurzbeschreibung

Dieses Repository ist eine zentrale Übung für Git, GitHub, Remote-Repositories und Synchronisation.

## Inhalt des Repositories

- README.md
- .gitignore
- notizen.txt

## Erste Nutzung oder Zweck

Das Repository dient zum Üben von Commits, Push, Pull und der Zusammenarbeit mit einem GitHub-Remote-Repository.
Diese README wurde für die Synchronisationsübung aktualisiert.

## Voraussetzungen

- Git ist installiert.
- Ein GitHub-Konto ist vorhanden.
- Eine SSH-Verbindung zu GitHub ist eingerichtet.

## Projektstruktur

- `README.md` – Projektdokumentation
- `.gitignore` – Regeln für Dateien, die Git ignorieren soll
- `notizen.txt` – Notizen zur Übung

## Nächste Schritte

- Änderungen mit Git dokumentieren.
- Push und Pull weiter üben.
- Mit Branches und Pull Requests arbeiten.
